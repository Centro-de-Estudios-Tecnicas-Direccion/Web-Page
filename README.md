## 🏛 Acerca del CETED

El **Centro de Estudios de Técnicas de Dirección (CETED)** es una institución universitaria docente-investigativa adscrita a la **Universidad de La Habana**, creada el **30 de marzo de 1988** por decisión de los niveles superiores de la dirección del país, con el objetivo de fortalecer el estudio y la enseñanza de la teoría y la práctica de la dirección en Cuba.

El CETED satisface necesidades de conocimientos, el desarrollo de habilidades y la solución de problemas en la esfera de la dirección y la gestión, con calidad y rapidez, para contribuir al desarrollo de organizaciones, dirigentes, profesores y estudiantes.

> *"Nuestro concepto es que para entrenar a directivos tiene que existir un espacio que no sea el aula clásica. Tiene que haber un espacio de intercambio, de socialización, de autonomía, que propicie el debate porque de ahí surgen las nuevas ideas."*  
> — **Dra.C. Katy C. Herrera Lemus**

## 📜 Historia y Misión

### Historia

| Año | Hito |
|-----|------|
| **1988** | Fundación del CETED por decisión de los niveles superiores de la dirección del país. |
| **1992** | Inicio de la **Maestría en Dirección**, primera en Cuba. |
| **2023** | Inauguración de la **Maestría en Gestión de Proyectos para el Desarrollo**. |
| **2024** | 36 aniversario de fundación. |
| **2025** | Creación de la **Cátedra UNESCO de Educación y Desarrollo de Economías Circulares**. |

### Misión

Formar, investigar y prestar servicios profesionales para el desarrollo de habilidades directivas en Cuba, contribuyendo al perfeccionamiento de la gestión organizacional y al desarrollo socioeconómico del país.

### Visión

Ser un referente nacional e internacional en la formación de directivos y en la investigación aplicada a las ciencias de la administración, con un enfoque innovador, multidisciplinario y comprometido con el desarrollo sostenible.

## 🌱 Redec — Cátedra UNESCO

La **Cátedra UNESCO de Educación y Desarrollo de Economías Circulares** fue creada en febrero de 2025, teniendo como antecedente la **Red Universitaria para el Desarrollo de la Economía Circular (Redec)**, instituida en 2025.

### Objetivos

- Dar a conocer la economía circular en el medio universitario y en las comunidades.
- Conectar proyectos estudiantiles con barrios donde existan problemas socioeconómicos.
- Promover la eficiencia en el uso de los recursos y su reaprovechamiento.

### Proyectos Destacados

| Proyecto | Descripción |
|----------|-------------|
| **Eco-retazos** | Tienda-boutique especializada en transformar materiales textiles recuperados en productos diferenciados. |
| **Círculo Violeta** | Empoderar a mujeres en temáticas de sostenibilidad y modelos de negocios sostenibles. |

## 🚀 Instalación y Desarrollo

### Requisitos Previos

- Node.js >= 20.19
- npm >= 10
- Git
- Python 3.11 y Docker (solo cuando exista el backend)

### Clonar el Repositorio

```bash
git clone https://github.com/ceted-uh/ceted-website.git
cd ceted-website
```

### Instalar Dependencias

```bash
cd frontend
npm install
```

### Configurar Variables de Entorno

```bash
cp .env.example .env
# Editar .env con la URL de la API cuando exista
```

### Iniciar Servidor de Desarrollo

```bash
npm run dev
```

La aplicación estará disponible en `http://localhost:5173`.

### Construir para Producción

```bash
npm run build
```

### Base de Datos

```bash
cd docker
cp .env.example .env   # credenciales de PostgreSQL
docker compose up -d
```

PostgreSQL queda en el puerto 5432 y Adminer, para inspeccionar la base de
datos, en el 8080.

## 🌐 Despliegue

El sitio se publica en **GitHub Pages** mediante GitHub Actions. Cada `push` a
`main` compila `frontend/` y lo publica; no hay que hacer nada mas.

**Poner en marcha por primera vez** (una sola vez, desde el repositorio en GitHub):

1. **Settings → Pages** → en *Build and deployment*, fuente **GitHub Actions**.
2. Subir este código con `git push`.
3. En la pestaña **Actions** se verá *Desplegar en GitHub Pages*. En menos de un
   minuto aparecerá un check verde.
4. El sitio quedará en:

   ```
   https://centro-de-estudios-tecnicas-direccion.github.io/Web-Page/
   ```

Para republicar sin tocar el código: en **Actions → Desplegar en GitHub Pages**
→ *Run workflow*.

### Cómo funciona

| Pieza | Para qué |
|---|---|
| `VITE_BASE_PATH` | GitHub Pages sirve bajo `/Web-Page/`, no en la raíz del dominio. El workflow lo deduce del nombre del repositorio. |
| `basename` en el router | Para que React Router resuelva las rutas dentro del subdirectorio. |
| `rutaAsset()` | Prefija con la ruta base las imágenes de `public/`, que si no darían 404. |
| `404.html` | GitHub Pages no sabe de enrutado. Sin este archivo, `/servicios` no funcionaría. Lo genera `scripts/postbuild.mjs`. |
| `.nojekyll` | Desactiva Jekyll, que borra cualquier ruta que empiece por `_`. |

### Probarlo en local antes de subir

```bash
cd frontend
npm run build:pages     # compila con la ruta base /Web-Page/
npx vite preview
```

### Cuando exista un dominio propio

Cambiar `VITE_BASE_PATH` a `/` en `.github/workflows/deploy-pages.yml` y añadir el
dominio en **Settings → Pages**. El código no necesita otros cambios.

### Con backend

La API se publica aparte. Al compilar se indica su dirección:

```bash
VITE_API_URL=https://api.ceted.uh.cu npm run build
```

## 🎨 Sistema de Identidad

La identidad visual del CETED está implementada como código, no descrita aparte:

- [`docs/IDENTIDAD.md`](docs/IDENTIDAD.md) — la guía de uso.
- [`frontend/src/styles/tokens.css`](frontend/src/styles/tokens.css) — la fuente
  de verdad: paleta, escala tipográfica, ritmo y formas.
- [`frontend/src/styles/base.css`](frontend/src/styles/base.css) — los recursos
  de marca: antetítulo, trama de decisión, vector y tratamiento fotográfico.

El azul institucional `#004CA5` se extrajo del logotipo oficial. El trazado
vectorial del logo se generó desde `docs/CETED.png` y se incrusta como
componente React, de modo que hereda el color del texto y no necesita variantes.

Regla práctica para el equipo: **ningún color ni tamaño se escribe suelto en
un componente.** Si hace falta uno nuevo, se añade al token.

## 🤝 Contribución

Las contribuciones son bienvenidas. Por favor, sigue estos pasos:

1. **Fork** el repositorio.
2. **Crea** una rama para tu funcionalidad (`git checkout -b feature/nueva-funcionalidad`).
3. **Commit** tus cambios (`git commit -m 'Añadir nueva funcionalidad'`).
4. **Push** a la rama (`git push origin feature/nueva-funcionalidad`).
5. **Abre** un Pull Request.

- **Commits:** Conventional Commits (`feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:`).
- **Código:** ESLint + Prettier.
